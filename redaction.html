Workflow

  1. Veille (UFC, ARES, Hexagone, PFL, ONE, KSW, clubs).
  2. Proposition de titres (agent).
  3. Sélection COM.
  4. Brouillon + plan (agent).
  5. SEO : title, meta, Hn, maillage.
  6. Relecture humaine obligatoire.
  7. Visuel (alt + nom de fichier propre).
  8. Publication (HTML dans articles/).
  9. Réseaux (3 phrases max, lien canonique).
  10. Ligne dans le suivi SEO.

Créer un article

À la racine du dépôt :

node tools/new-article.mjs slug-url "Titre de l’article" "Kicker"

Le script copie tools/template-article.html vers articles/slug-url.html. Ensuite : rédiger, relier depuis Actualités, ajouter l’URL au sitemap.xml.

Prompt type (agent)

Tu rédiges pour UFC.FR, média MMA indépendant francophone.
Ton : clair, neutre, informatif. Pas officiel UFC.
N’invente aucun résultat, palmarès, citation ni date.
Si une info n’est pas sourcée, écris « à confirmer ».
Structure : chapô, H2, listes si utile, maillage interne.
Title < 60 car. Meta description < 155 car.
Mots-clés naturels : MMA France, résultats, clubs, organisations.
Terminer par 3 liens internes.

Interdit

  • Publication automatique vers le site public.
  • Citations sans source.
  • Articles de moins de ~500 mots utiles.
  • Ton promo hors portrait de club identifié.
