Suivi SEO

Pas de chiffre inventé. Cette page est le carnet de bord : à remplir dès que Search Console est branchée sur le domaine.

Déjà en place sur le recodage

  • Title et meta description par page
  • Canonical https://www.ufc.fr/…
  • Hn structurés, maillage interne
  • robots.txt + sitemap.xml
  • Alt sur le logo ; visuels d’article à légender
  • Dates de publication / mise à jour

À faire à la bascule domaine

  1. Propriété Search Console sur www.ufc.fr.
  2. Envoyer sitemap.xml.
  3. Coller le code de vérification dans le <head> (ne pas inventer d’ID ici).
  4. Analytics : coller un ID réel, jamais un faux G-XXXX.
  5. 301 depuis les URLs WordPress encore utiles.
