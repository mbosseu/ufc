Suivi SEO UFC.FR — méthode

Rédaction UFC.FR · Publié le 31 août 2026

Le cahier des charges demande un suivi des performances SEO. Site Kit (Google) est déjà installé sur UFC.FR. Cette page fixe la méthode. Les chiffres se lisent dans Search Console / Analytics, pas ici — on ne publie pas de vanité metrics inventées.

Où regarder (wp-admin)

  1. Site Kit → Search Console : impressions, clics, position moyenne, 28 jours vs 3 mois.
  2. Requêtes à filtrer : ufc paris 2026, parnasse ufc, carte ufc paris, club mma toulouse, champions mma, mma france.
  3. Pages : les URLs publiées le 31 août 2026 (dossier Paris, champions, clubs) — indexation sous 48–72 h typiquement, parfois plus.

Ce qui a été posé le 31 août 2026

  • titles / metas Yoast sur les nouveaux contenus ;
  • slugs propres ;
  • maillage interne (Paris ↔ champions ↔ clubs) ;
  • dates de publication et de MAJ dans les textes ;
  • disclaimer média indépendant ( entité Organization Yoast à surveiller : ne pas se présenter comme UFC officiel).

Cadence

Après l’UFC Paris : vérifier l’indexation des résultats, la requête résultats ufc paris, et corriger les metas si Google affiche un snippet trop court. Tous les 15 jours : passe champions + classements.

Page interne COM, pas un rapport public chiffré.
